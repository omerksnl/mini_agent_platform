- FastAPI, SQLAlchemy, PostgreSQL, Alembic, Redis, and pytest

## Low Priority

- Python and object-oriented programming
- SQL, HTTP, JSON, and relational-database fundamentals
- Git, Linux, testing, and debugging

## Common Bonus

- End-to-end project ownership
- Measurable reliability, security, or performance improvement
- Clear documentation and technical trade-off communication

- End-to-end firmware feature ownership
